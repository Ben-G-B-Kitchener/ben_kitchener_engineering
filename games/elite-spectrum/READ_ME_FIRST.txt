ELITE / ZX SPECTRUM WEBSITE INTEGRATION

There are two routes on elite-spectrum.html:

1. Working third-party version: click Open game in a new tab. This is the same OldGames.sk version which the site owner has tested successfully. The embedded frame is an optional experiment: some sites prohibit framing; the new-tab link remains the reliable fallback.

2. JSSpeccy 3 self-hosted emulator: the runtime is NOT bundled because this environment could not download it. Run `python games/elite-spectrum/install_player.py` with network access, or get the release directly from https://github.com/gasman/jsspeccy3/releases . It has to be installed before Start emulator works. Use Open game file to select your own .z80/.sna/.tap/.tzx file. For private local use only, the installer also offers --private-game; do not publish the game file without verifying copyright permissions.

No claim is made that the OldGames.sk site permits iframe embedding. The direct link is the reliably working option confirmed by the owner. The JSSpeccy local runtime is not verified in browser in this delivery.

Note: No changes made to Galactic Trader or existing site's title/meta blocks.
